About the project

Turning an image into a more informed conversation.

Hair Disease Detection is a machine learning web application created as an academic project. It combines a Django interface with an image classification model to provide an initial prediction for selected hair and scalp conditions.

01

What it does

The application accepts a hair or scalp image, prepares it for analysis, and sends it through a trained DenseNet-based model with an SVM classification layer. It then displays the most likely class and links to background information about that condition.

02

Supported conditions

  • Alopecia Areata
  • Folliculitis
  • Psoriasis
03

How to use it

Open Detection, choose a clear image, submit it, and review the predicted label. Better lighting and a focused image can help produce a more useful result.

Important note

This tool is for education and preliminary screening only. It is not a medical diagnosis. Please consult a qualified healthcare professional for persistent symptoms, uncertainty, or treatment decisions.
